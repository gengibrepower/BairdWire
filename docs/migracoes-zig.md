# Migrações do Zig

O registro de cada migração de versão do Zig (ADR 0028): o que quebrou e como foi resolvido. Uma entrada por migração, da mais recente para a mais antiga.

## Formato

```
## 0.N → 0.N+1

- **Branch:** `zig-0.N+1`
- **Release do Zig:** data · **Migração:** data
- **Dependências:** como cada lib acompanhou (commit novo, fork ou espera)

### O que quebrou
- ...

### Como foi resolvido
- ...

### Para a próxima
- ...
```

## Versão inicial

O projeto começou na **0.17.1** (ADR 0034). Não houve migração.
